# 你说我猜 🎉

极简派对小游戏 — 纯静态网页，手机端友好。

## 功能

- 📂 **11个类别**：动物、食物、日常用品、职业、运动、影视/明星、成语、地点/城市、医学、校园、科技
- 🔀 **混合模式**：支持多类别混合出题
- ⏱️ **3档时长**：3分钟 / 5分钟 / 8分钟
- ⏭️ **跳过限制**：每轮最多跳过2次
- 🏆 **及格阈值**：根据时长设定目标
- 💾 **智能去重**：localStorage缓存已出词，永不重复
- 📱 **移动端优先**：大按钮、大字体，手机体验友好

## 部署

纯静态站点，零构建步骤。

### GitHub Pages

直接 push 即可。

### Cloudflare Pages

1. 连接 GitHub 仓库
2. Build command: 留空
3. Build output directory: `/`
